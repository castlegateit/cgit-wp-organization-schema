# Castlegate IT WP Organization Schema

A very simple [Organization Schema](https://schema.org/Organization) generator for WordPress, using [Advanced Custom Fields Pro](https://www.advancedcustomfields.com/) to provide fields for data entry and [Schema Map](https://github.com/castlegateit/cgit-wp-schema-map) to output valid Schema.org structured data. Any sub-type of the basic Organization schema can be selected.

## Yoast

The plugin removes the Organization schema output by Yoast to prevent duplicate data appearing on the site.

## Google Maps API

The Google Maps location field on the Organization options page requires an API key. You can find out how to add the API key in the [Advanced Custom Fields documentation](https://www.advancedcustomfields.com/blog/google-maps-api-settings/).
